# Kanban Board (локальная сеть)

Канбан-доска с событиями, уведомлениями, погодой Москвы и ИИ-ассистентом Big Pickle.

## Запуск (HTTPS + автозапуск)

Сервис установлен как systemd-сервис `kanban-board` и **стартует сам при загрузке системы**.

```bash
systemctl status kanban-board        # статус
systemctl restart kanban-board       # перезапуск
systemctl stop kanban-board          # остановка
systemctl disable kanban-board       # отключить автозапуск
```

### Локально (на ПК)
- **http://localhost:8080** — микрофон, голосовой ввод и wake-слово работают **в любом браузере** (localhost автоматически считается безопасным контекстом). Chrome/Chromium Required для wake-слова, Firefox — для ручной записи голоса.
- **https://localhost:8443** — тоже работает, но требует доверия к сертификату CA.

### По локальной сети (телефон)
- **https://<IP-компьютера>:8443** — микрофон требует установленный CA-сертификат.
- **http://<IP-компьютера>:8080** — редиректит на HTTPS (микрофон будет заблокирован до установки CA).
1. Откройте `https://<IP>:8443/ca.pem`, скачайте сертификат.
2. Android: Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → CA → выбрать файл.
   iPhone/личный Chrome: просто откройте сначала `http://<IP>:8080`, подтвердите предупреждение (микрофон потребует доверенный HTTPS; лучше установить CA).

## ИИ-ассистент (Big Pickle)
Подключается к Big Pickle **как opencode**: через локальный CLI `opencode run -m opencode/big-pickle`
(шлюз OpenCode Zen Gateway авторизует автоматически). Ключи/URL не нужны.

- **Текст / Голос 🎙️ / Фото 🖼️** — чат (кнопка 🤖). Ответы стримятся.
- **Работа с файлами ПК**: ассистент создаёт проекты и пишет код в рабочей папке
  (по умолчанию `~/AI Projects`, меняется в ⚙️ → ИИ). Права задаются в `ai-opencode.json`
  (запись разрешена, деструктивные bash-команды и секретные каталоги запрещены).
- **Голосовой ввод 🎙️** в чате: записывает сообщение и **распознаёт локально** (faster-whisper, offline, в `stt/`) — работает в любом браузере. В Chromium/Chrome может использовать встроенное распознавание.
- **Голосовая активация**: кнопка 🎤 в шапке — постоянное прослушивание.
  Скажите «Саша / Саня / Александр / Алекс…» и затем команду (ответ озвучивается).
  Требует безопасного контекста — **открывайте http://localhost:8080**. Работает в Chrome/Chromium
  (в браузере) и в Firefox (через серверное распознавание).

## Погода
Open-Meteo (без ключа), Москва. Текущая + почасовая на 24 ч + прогноз на завтра (клик по виджету в шапке).

## Данные
`data/db.json` (доска, события, настройки фона), загруженные картинки — `uploads/`,
пример фона — карта Азерота из WoW (`/uploads/up-mtzsyzgv4yh367.jpg`).

## Настройки
Панель ⚙️: фон (цвет/градиент/изображение + размытие/затемнение), параметры ИИ (путь к opencode, рабочая папка, модель, промпт).

## Файлы
- `server.js` — сервер без внешних зависимостей (HTTP/HTTPS, REST, прокси погоды и AI)
- `ssl/` — ключи и сертификаты (не передавать третьим лицам)
- `ai-opencode.json` — права ассистента для opencode CLI
- `stt/` — локальное распознавание речи (faster-whisper, офлайн)
- `start.sh` / `start-lan.sh` — ручной запуск (без systemd)
