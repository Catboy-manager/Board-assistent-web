# Kanban Board (локальная сеть)

Личная канбан-доска + ИИ-ассистент + новостная лента + «что посмотреть», которые живут на вашем ПК и открываются в браузере (в том числе с телефона в локальной сети). Всё хранится только у вас: интернет нужен лишь для фильмов, новостей, музыки, умного дома и ИИ.

Возможности коротко: доска задач с колонками/карточками, напоминания, ИИ-ассистент Big Pickle (текст/голос/фото), фильмы с постерами, новости с оценками интереса, локальная музыка, игры Steam, статистика уведомлений, YouTube с подборками по интересам, звуки уведомлений, умный дом (LAN + Яндекс Станция), пересылка уведомлений со смартфона, глобальный зум интерфейса.

## Системные требования

- Node.js ≥ 18 (глобальный `fetch`)
- Linux
- Интернет (для контента и ИИ)
- Опционально: Python 3 + `faster-whisper` + `torch` — локальное распознавание речи; piper + модель `data/tts` — озвучка ответов

## Запуск

### Как сервис (автозапуск)

Сервис установлен как systemd-сервис `kanban-board` и **стартует сам при загрузке**:

```bash
systemctl status kanban-board        # статус
systemctl restart kanban-board       # перезапуск
systemctl stop kanban-board          # остановка
systemctl disable kanban-board       # отключить автозапуск
```

### Вручную (без systemd)

```bash
node server.js            # HTTP 8080 + HTTPS 8443
```

Скрипты `start.sh` / `start-lan.sh` — обёртки для ручного запуска.

### Отладка

```bash
node --check server.js     # проверка синтаксиса
curl -s http://127.0.0.1:8080/api/ping
```

## Как открыть

### На этом же ПК
- **http://localhost:8080** — микрофон и голосовой ввод работают в любом браузере (localhost считается безопасным контекстом).
- **https://localhost:8443** — тоже работает, но требует доверия к сертификату CA.

### По локальной сети (телефон)
- **http://<IP-ПК>:8080** — базовый доступ. Микрофон будет заблокирован до установки CA.
- **https://<IP-ПК>:8443** — микрофон требует установленный CA-сертификат.

Установка сертификата CA с телефона:
1. Откройте `https://<IP>:8443/ca.pem`, скачайте сертификат.
2. Android: Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → CA → выбрать файл.
3. iPhone: откройте сначала `http://<IP>:8080` и подтвердите предупреждение; для микрофона установите CA.

По умолчанию ПК слушает `0.0.0.0` (LAN `192.168.1.100`), порты 8080 (HTTP) / 8443 (HTTPS).

## Пересылка уведомлений со смартфона (важно)

Самая полезная связка: уведомления со смартфона приходят на доску (всплывающие + вкладка 🔔).

- **Вручную:** откройте на телефоне `http://<IP>:8080/notify.html` и отправьте тест.
- **Авто:** настройте приложение-автоматизацию (HTTP Shortcuts / MacroDroid / Tasker) слать POST на `http://192.168.1.100:8080/api/notify/send` с JSON `{ "title": "...", "text": "...", "app": "...", "chat": "..." }`. Опционально: заголовок `x-notify-key: <ключ>` (ключ задаётся переменной `KANBAN_NOTIFY_KEY`).

Браузер держит максимум 6 соединений на хост — поэтому история уведомлений и прогресс импорта опрашиваются короткими запросами, а не отдельными SSE-потоками.

## ИИ-ассистент (Big Pickle)

Подключается **как opencode**: через локальный CLI `opencode run -m opencode/big-pickle` (шлюз OpenCode Zen Gateway авторизует автоматически, ключи/URL не нужны).

- **Текст / Голос 🎙️ / Фото 🖼️** — чат (кнопка 🤖), ответы стримятся.
- **Работа с файлами ПК** — ассистент создаёт проекты и пишет код в рабочей папке (по умолчанию `~/AI Projects`, меняется в ⚙️ → ИИ). Права задаются в `ai-opencode.json` (деструктивные bash-команды и секретные каталоги запрещены).
- **Голосовой ввод 🎙️** в чате — распознаётся локально (faster-whisper, офлайн в `stt/`), работает в любом браузере.
- **Голосовая активация (wake-слово) отключена** — код остался (`public/js/wake.js`), но кнопка 🎤 в шапке убрана и не подключается.

Конфигурация ИИ (режим, opencode, рабочая папка, модель, промпт) — в панели ⚙️. Секретный `apiKey` не отдаётся по сети: сервер возвращает только флаг `hasApiKey`, а пустое поле в форме означает «не менять сохранённый ключ».

## Что ещё есть

- **Погода** — Open-Meteo (без ключа), Москва: текущая + почасовая на 24 ч + завтра (клик по виджету).
- **Фильмы 🎬** — список с постерами (Bing Images + фолбэк-резолвер), отметить просмотренным, удалить; авто-подтяжка постеров фоном.
- **Новости 🗞** — сводка за сегодня/вчера (RSS: Лента, РИА, ТАСС, Коммерсантъ, Хабр, NASA), оценки интереса (😞-2 … 🤩+2), пер-категорийные веса, ✨ ИИ-сводка.
- **Музыка 🎵** — лайв-плеер локальных файлов (`~/Music`), стрим с Range, оценки, загрузка/удаление.
- **Игры 🎮** — библиотека Steam + сторонние, конфиг SteamId/API, поиск в каталоге GOG/Steam.
- **Статистика 📨** — сколько уведомлений, активных дней, в день.
- **YouTube ▶** — поиск, стрим с сервера (yt-dlp), авторизация (cookies/браузер), история и подборки по интересам.
- **Cookies → Интересы 🍪** — импорт cookies **и истории посещений** из браузера (Chrome/Firefox, кросс-платформенные пути) с прогрессом и живым логом; авто-темы, «портрет человека».
- **Звуки 🔊** — 10 встроенных + загрузка своих; правила по подстроке (app/title/text), громкость.
- **Умный дом 🏠** — LAN-скан, устройства, опрос → diff → события (SSE), сценарии, адаптер Яндекс Станции (Glagol), ключ `KANBAN_SMART_KEY`.
- **Глобальный зум** — Ctrl+колесо, кнопки `−/1:1/+`, корректный drag/resize под любым зумом.
- **Справка ❓** — кнопка в шапке: 12 разделов простым языком (про пересылку уведомлений — отдельный раздел).

## Данные и настройки

- `data/db.json` — доска, события, настройки
- `data/*.json` — новости, фильмы, игры, звуки, умный дом и т.д.
- `uploads/` — загруженные картинки и звуки
- `config.json` — настройки (порт, город, ИИ, Telegram, Steam). **Содержит секреты** — не коммитить и не отдавать третьим лицам
- `ssl/` — ключи и сертификаты (не передавать)
- `ai-opencode.json` — права ассистента для opencode CLI
- `stt/` — локальное распознавание речи (faster-whisper, офлайн)
- `data/tts` — модель piper для озвучки

## Безопасность

- Сервер слушает `0.0.0.0` (весь LAN). Основные API (доска, конфиг, уведомления) **без авторизации** — это персональный инструмент для домашней сети, а не публичный сервис. Не выводите его в интернет без reverse-proxy с аутентификацией.
- Секреты не отдаются по сети: `apiKey` ИИ скрыт (`hasApiKey`), токен Telegram хранится только в `config.json`.
- Опциональные ключи: `KANBAN_NOTIFY_KEY` (POST `/api/notify/send`), `KANBAN_SMART_KEY` (все POST умного дома), `KANBAN_CONSOLE_KEY` (консоль).
- Path traversal закрыт на всех файловых эндпоинтах (`/uploads/`, `/api/file`, музыка, проекты).
- Telegram API с RU-сетей недоступен напрямую — нужен `HTTPS_PROXY`/`ALL_PROXY` или зеркало `TELEGRAM_API_BASE`.

## Ключевые файлы

- `server.js` — сервер без внешних зависимостей (HTTP/HTTPS, REST, прокси погоды и AI)
- `sounds.js`, `movies.js`, `news.js`, `games.js`, `messages.js`, `youtube.js`, `smart.js`, `notify.js`, `music.js` — модули фич (держать новые фичи в модулях, не в `server.js`)
- `public/` — фронтенд (`js/`, `css/`, `sounds/`, `index.html`, `notify.html`)

## Troubleshooting

- **Сервис не поднимается:** `journalctl -u kanban-board -n 50`, затем `node --check server.js`.
- **Нет звука уведомлений:** проверьте 🔊 в side-widget (по умолчанию `notify`), громкость и что браузер не блокирует autoplay.
- **Микрофон на телефоне заблокирован:** нужен HTTPS + установленный CA (см. «Как открыть»).
- **Импорт cookies «ничего не меняется»:** импорт читает и **историю посещений** (не только cookies), поэтому изменения появляются не сразу; смотрите живой лог в 🍪.
- **Умный дом не видит станции:** mDNS-сканер должен биндиться на порт 5353 (иначе станции игнорируют запросы).
